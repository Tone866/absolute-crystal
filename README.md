## Information 

A German Pokemon Crystal Romhack.  
Ein deutscher Pokemon Kristall Romhack.

folgende Features wurden ergänzt:
- Laufschuhe
- alle Pokemon fangbar
- Tausch-NPC für Tauschentwicklungen
- alle NPC + Arenen sind bereit für eine Revanche
- Hunduster in Johto fangbar
- weniger Schritte für Eier nötig
- niedriger KP-Beep, piept jetzt nur noch 3x
- ein paar mehr Kämpfe mit besonderen Personen

## Setup

For more information, please see [INSTALL.md](INSTALL.md)

After setup has been completed, you can choose which version you wish to build.
To build a specific version, run this command inside the repository directory in cygwin64:

`make`
